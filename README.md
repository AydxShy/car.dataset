Used Toyota Car Price Prediction

Project Overview
This project uses ML to predict the prices of used Toyota vehicle listings.

Dataset
The dataset was obtained from a publicly available source. The link is included within the project.

Methodology
- Data cleaning and preprocessing
- Train-test split (80/20)
- K-fold cross-validation
- Implementation of multiple regression models using Scikit-learn
- Hyperparameter tuning and model comparison

Repository Structure
`car_dataset.csv` – Dataset file
sed_car.ipynb` – Google Colab Notebook containing all analysis and model implementation

Tools Used
- Python
- Scikit-learn
- Pandas
- NumPy
- Matplotlib
